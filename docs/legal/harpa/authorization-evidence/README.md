# Authorization Evidence

Este diretorio e reservado para evidencia externa formal relacionada aos direitos e a autorizacao da Harpa.

EVIDENCE_STATUS=NO_EXTERNAL_EVIDENCE_ARCHIVED_YET

A existencia deste diretorio nao significa que uma autorizacao externa formal ja tenha sido recebida ou documentada.

## Requisitos para evidencia futura

Quando um artefato real for recebido e aprovado para arquivamento, seu registro deve conter, quando aplicavel:

- nome do documento;
- tipo do documento;
- emissor ou origem;
- data de recebimento;
- escopo representado pelo documento;
- SHA-256 do artefato arquivado;
- relacao com a edicao ou fonte da Harpa;
- status de revisao;
- observacoes necessarias para rastreabilidade.

## Regras de integridade

FABRICATED_AUTHORIZATION_ALLOWED=NO
RECONSTRUCTED_AUTHORIZATION_ALLOWED=NO
PLACEHOLDER_PRETENDING_TO_BE_EVIDENCE_ALLOWED=NO
EVIDENCE_WITHOUT_PROVENANCE_ALLOWED=NO
SILENT_EVIDENCE_REPLACEMENT_ALLOWED=NO

Um README, anotacao interna, decisao operacional ou placeholder nao pode ser promovido a evidencia externa formal.

Arquivos reais adicionados futuramente devem manter sua identidade e proveniencia verificaveis.

## Relacao com o manifesto

O estado juridico/editorial consolidado permanece em ../harpa-rights-manifest.md.

Enquanto nenhuma evidencia externa formal estiver arquivada, o manifesto deve preservar:

FORMAL_EXTERNAL_AUTHORIZATION_STATUS=IN_PROGRESS
FORMAL_EXTERNAL_AUTHORIZATION_EVIDENCE_ARCHIVED=NO
